# 关于我页面

在 Halo 中新建一个独立页面，标题可填「关于我」，模板选择「关于我」。在扩展设置中开启「关闭侧边栏」，可以获得更宽的介绍与作品展示区域。

主题设置中的「关于我」分组负责开场介绍、关键词、近况和作品。昵称与头像沿用「博主卡片」配置；没有单独设置时使用页面作者信息。社交账号也沿用「博主卡片」中的配置，不需要开启侧栏上的社交账号显示开关。

开场头像支持点击招呼、关键词浮动和鼠标跟随，近况与作品在滚动时进入。系统「减少动态效果」、控制中心的动画开关与主题简洁模式都会关闭动画。

开场下方可展示真实的文章、分类和标签数量。工具箱与近况在桌面上并排，生活兴趣与最近三篇公开文章组成另一组双栏，在手机上自动改为单栏。工具箱和兴趣未填写时自动收起；站点记录与最近文章可以分别关闭。

「主题设置 → 关于我 → 常用工具」按分组维护工具。点击分组后，在「工具列表」中逐项添加或编辑工具名称与 Iconify 图标，图标和颜色都可自行选择，分组图标也能修改。自己选择的图标优先，未选择时才按工具名称匹配默认图标；旧版逗号分隔内容仍能展示。

「最近在忙什么」维护近况，每条填写标题和简短说明。「关于页设计 → 页面模块」调整这两个模块的展示标题、顺序、宽度和开关。

「生活的另一面」中的小图案使用 Iconify 选择器，可搜索图标并设置颜色，再填写兴趣名称和一句话说明。原有的键盘、耳机、相机等 emoji 会转换为对应图标显示。

作品没有封面时会生成主题配色的文字展示图。作品类型有两种及以上时，会自动显示分类筛选；相同类型请使用相同名称，例如「Halo 主题」「Halo 插件」。空白正文不会显示故事卡片。

个人照片可放在页面封面中，显示在作品后面的故事区。页面编辑器中的正文也在这里展示，支持原有的图片与正文排版。

下面是偏向技术开发与开源作品的文案草稿，使用前请按自己的实际情况修改。

## 开场

标题：

> 把想法，
> 慢慢做成作品。

一句话介绍：

> 喜欢把重复的事情交给工具，把值得记住的日常留在这里。
> 这个小站，装着我的开发记录、开源作品和生活片段。

关键词可填：`开发,开源,折腾,生活记录`。

## 近况与作品

近况建议写两到三条真正正在做的事，每条用一句话说明。例如：

- 打磨一个项目：最近在解决什么问题，或希望改善什么体验。
- 学习与尝试：最近正在动手实践的一项技术。
- 工作之外：想持续记录的一件小事。

作品建议精选两到四个，写清楚名称、类型、解决的问题与访问地址。地址可填完整的 http(s) 链接或以 `/` 开头的站内路径；留空时作品仅供展示。封面可留空，适合没有截图的插件或工具。

## 故事正文

以下内容可直接放入页面编辑器，再按自己的经历调整：

```markdown
我喜欢折腾，也喜欢把折腾过的东西整理下来。代码、主题和插件，是把想法做出来的方式；写博客，是让这些过程有迹可循。

这里会写解决过的问题，也会留下一些不那么有用、但想记住的日常。比起急着得到答案，我更喜欢在动手的过程中慢慢弄明白。
```

不想展示某个部分时，可以清空相应内容。页面扩展中的「隐藏页面标题」会隐藏开场大标题，正文宽度继续作用于故事区。

## 彩色卡片与自定义设计

「关于我」维护内容；「关于页设计」维护布局和动效。关于页可单独设置昵称、头像、状态、签名、轮换短句、招呼语、背景图和两个按钮，不必跟随侧栏内容。

在「页面模块」中拖动条目即可排序，逐项设置标题、小标题、桌面宽度、预设配色或自定义背景与文字颜色。关闭或移除条目会隐藏模块，重复的内置模块类型只显示第一个。自由内容卡可以重复添加，自行填写标题、正文、图片与按钮，并单独设置宽度和颜色。工具箱、近况、作品、兴趣、最近文章、故事和联系入口均可独立调整。

整体设计支持彩色卡片与主题配色两种风格，开场配色、头像形状与大小、卡片圆角、间距、标题大小、技能排列、作品列数均可调整。手机上自动改为单列。

动效可选活泼、轻柔或关闭，并设置速度。标题拆字、鼠标跟随、环境动画、技能浮动、封面视差和头像粒子均有独立开关。系统减少动态效果、控制中心动画开关与主题简洁模式优先于这些配置。

## 影像作者页

「关于页设计 → 整体风格」选择「影像作者页」。这个模式铺满浏览器宽度，导航浮在照片上方，不展示普通页面侧栏。首屏高度设为 100 即可铺满视口；顶部导航透明，下滑时收起，上滑时重新显示。滚动时照片保留原有亮度并逐渐虚化，固定身份栏及「个人资料 / 站内动态」切换位于下方，资料区沿用可编排的模块。

- 在「关于我 → 开场背景图」设置适合横向裁切的照片；留空使用现有头像作为示例。
- 「主视觉前景人物」可叠放一张透明背景人物图，获得前景与背景分层的效果。图片由站长自行提供。
- 「主视觉背景文字」可以写昵称或域名；「资料页简介」填写个人介绍。
- 「个人资料分组」可以自由添加名称与值，例如工作、兴趣、所在城市；未填写时不展示。
- 可设置首屏高度、照片焦点、暗部遮罩和默认打开的内容。动态面板读取站点最近六篇公开文章。
- 首屏主、副按钮与卡片模式共用「关于我」中的文字、地址和显示开关。跳转到作品或联系模块时，会自动切回个人资料；对应模块不存在时隐藏锚点按钮。
- 减少动态效果时保留照片和内容切换，停止视差与渐入。
